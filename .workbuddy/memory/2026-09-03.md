# 2026-09-03

## MqttRustUI 项目启动 · 架构方案设计

从空仓库起步，产出完整架构设计方案 `DESIGN.md`（项目根目录）。

### 关键技术判断
- 确认 `rumqttc` 0.25 依赖 tokio TcpStream，**无法编译到 wasm**，Web 端必须另起炉灶。
- 解法：复用 `mqttbytes`（rumqtt 分离出的纯编解码 crate，无 IO，wasm 可编译）+ 自研 web-sys WebSocket transport + 自研薄会话层。约 500-800 行自研代码。
- 桌面框架定 Tauri 2（排除 Electron 体积、Wails 后端是 Go、iced/egui 生态）。
- Web 端把 Rust 核心放进 **Web Worker**，与桌面端"WebView + Rust 后端进程"结构对称，前端只实现一次 PlatformBridge。
- 性能关键点：消息必须批量推送（50ms / 200 条双阈值）+ 环形缓冲 + 虚拟滚动，逐条推送会打爆 WebView。

### 用户追加要求：轻量持久化
用户明确不要用 IndexedDB 和 SQLite，配置改用 JSON 文件存储。据此调整：
- `mqttkit-store` → `mqttkit-config`（native.rs 走 tokio::fs 原子写 / wasm.rs 走浏览器 Storage / vault.rs 凭据保险库 / migrate.rs 版本迁移）
- 持久化职责收窄为**只存配置，不存消息历史**；消息改内存环形缓冲（10 万条）+ 手动导出 JSONL
- 配置中凭据只存 `credential_ref` 引用，真值留 OS Keychain，配置文件可安全备份/入库
- 移除依赖 sea-orm / sqlx / idb，改 serde_json + tokio::fs + web-sys(Storage)
- Web 端说明：浏览器沙箱无法静默写磁盘文件，用浏览器 Storage 作落点 + JSON 文件导入导出

### 踩坑
show_widget 的沙箱会拦截 widget_code 中出现 `localStorage` 字面量的 SVG，改用"浏览器 Storage"措辞后通过。

### 待用户拍板

## v0.2 修订：范围收窄到桌面端

用户明确"先不考虑 web 端，再优化一下"。据此重写 DESIGN.md 为桌面端专注版。

### 结构上做减法
- crate 从 6 个精简到 3 个：`mqttkit-core`（连接状态机/会话/环形缓冲/payload 编解码/rhai）、`mqttkit-config`（AppConfig + 原子写 + keyring + 迁移）、`mqttkit-ipc`（契约 DTO）。
- 砍掉 `mqttkit-protocol`（直接用 rumqttc 编解码）、`mqttkit-transport`（直接用 rumqttc）、`mqttkit-store`（改 config）。
- 去掉所有 `cfg(target_arch = "wasm32")` 分支，移除 mqttbytes / web-sys / wasm-bindgen 依赖。

### 关键约束（新增）
**`mqttkit-core` 不得依赖 Tauri**，也不得让 rumqttc 类型泄漏到 core 对外接口 —— 既保证核心可脱离 GUI 单测，也为将来 wasm 化留口子。

### 桌面端深化的内容
- 连接状态机 6 态：Idle / Connecting / Connected / Reconnecting / Failed / Disconnecting
- 重连参数：初始 1s，倍数 1.8，上限 30s，抖动 ±20%，最多 10 次，单连超时 10s
- **重连后订阅重放的条件差异**（易错点）：clean_session=true 必须重放 SUBSCRIBE；clean_session=false / session_expiry>0 由 broker 保留订阅，重放会产生重复订阅
- 背压三档：<70% 正常 50ms/200 条；70-95% 降到 20ms；>95% 丢弃最旧；IPC 积压 >5000 降级为只推 Stats（回落到 1000 以下自动恢复）
- 环形缓冲用 VecDeque，10 万条/连接，溢出 pop_front 并累计 dropped
- 大 payload：预览截断 1KB，>64KB 不自动渲染
- 桌面原生能力：托盘、原生菜单、全局快捷键、单实例、mqtt:// 深链接、.mqttkit 文件关联、窗口记忆、自动更新、通知、日志轮转
- UI 三栏布局：连接列表 240px / Topic 树 260px / 消息区（虚拟滚动）+ 底部发布区

### 路线图
M0 骨架 → M1 核心链路 → M2 持久化与安全 → M3 稳定性（MVP 发布）→ M4 增强 → M5 分发

## 五决策落地 + M0/M1 代码实现

用户拍板：Ant Design Vue / MQTT 3.1.1+5.0 同时支持 / 不做主密码 / 不做自动更新 / 遥测默认关闭且需显式授权。随后要求直接实现代码（本机不执行，给 WSL 命令清单）。

### 已落地的代码（未编译，待用户在 WSL 跑）
- workspace 根 `Cargo.toml` + `crates/{mqttkit-ipc, mqttkit-config, mqttkit-core}` 三个 crate + `apps/desktop/src-tauri`（Tauri 2 壳）+ `ui/`（Vue3+AntDV+Vite）。
- `mqttkit-ipc`：共享领域模型（Connection/Subscription/TlsConfig/ProtocolVersion/Qos/ConnectionState/StoredMessage/AppSettings）+ command/event DTO。
- `mqttkit-config`：AppConfig 模型、JSON 原子写（tmp+rename）+ debounce + 损坏 `.bak` 兜底、keyring 保险库（无后端降级内存）、schema 迁移占位。
- `mqttkit-core`（不依赖 Tauri）：`protocol.rs`（rumqttc 接入 + 3.1.1/5.0 抽象 + TLS/代理/遗嘱）、`conn/`（ConnectionManager 多连接 + EventLoop 轮询 + 指数退避重连 + 订阅重放 + 全局批量 flush + 三档背压降级）、`session/`（重放决策）、`buffer/`（环形缓冲）、`topic/`（通配符匹配+树）、`stats/`、`codec/`、`script/`（rhai 骨架）。
- 桌面壳：`main.rs`（装配+自动连接+单实例+菜单+托盘）、`commands.rs`（薄命令层）、`state.rs`（TauriSink 事件出口）、`tray.rs`/`menu.rs`/`logging.rs`（tracing 脱敏 Layer + 文件轮转）。
- 前端：`api/backend.ts`（invoke+listen 封装）、Pinia stores（connections/messages/settings）、`MainView` + `ConnectionList`/`TopicTree`/`MessageList`(虚拟滚动)/`PublishPanel`。
- 文档：`DESIGN.md` §13 标记五决策已确认并移除主密码/自动更新相关描述；新增 `RUN_WSL.md`（WSL 环境/构建/运行清单）+ `.gitignore`。
